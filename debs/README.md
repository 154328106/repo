# DEB 软件包目录

这里存放已经确认适用于 Relaxin / RootHide 的 `.deb` 软件包。

操作教程分为两份：

- [01-推送软件包教程.md](01-推送软件包教程.md)：把新的 DEB 放进仓库、提交、推送，并检查自动发布结果。
- [02-修改DEB普通信息教程.md](02-修改DEB普通信息教程.md)：解包并修改名称、版本、作者、图标、描述等 `DEBIAN/control` 信息。

日常推送可以直接双击 [一键推送插件.bat](一键推送插件.bat)，按窗口提示选择插件和分类。脚本会调用同目录的 `push-deb.ps1` 完成分类记录、精确暂存、提交、推送和 Actions 检查。

软件源统一使用三个分类：`依赖插件`、`美化插件`、`功能插件`。分类只作用于软件源索引，不修改原始 DEB。

上传前至少确认以下事项：

- 软件包确实兼容 RootHide；
- `Architecture` 是 `iphoneos-arm64e` 或 `all`；
- 作者或许可证允许重新分发；
- 不是付费、破解或绑定特定账户的软件包；
- 不要把仅仅改过架构文字、实际却不兼容 RootHide 的软件包上传到源里。

当前仓库的自动构建会拒绝损坏的软件包、不支持的架构，以及 `Package + Version + Architecture` 完全重复的包。
